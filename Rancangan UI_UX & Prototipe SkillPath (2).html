Cetak Biru Arsitektur & Skema Database

Spesifikasi teknis integrasi antara CMS Pengembang, Engine AI, dan Tampilan Pengguna.

Skema Tabel Database

1. Learning_Tracks

- track_id (PK)
- title, category, description

2. Nodes_Material

- node_id (PK), track_id (FK)
- title, text_summary, pdf_url

3. AI_Generated_Quizzes

- quiz_id (PK), node_id (FK)
- question, options (JSON)
- answer, explanation

Alur Data Sistem
  1. Input CMS: Pengembang memasukkan ringkasan/file PDF materi.
  2. Prompt API AI: Teks materi dikirim ke LLM API dengan instruksi JSON terstruktur.
  3. Generasi Soal: AI mengembalikan 2-3 soal Pilihan Ganda & Flashcard.
  4. Node Sync: Soal disimpan ke DB dan Node baru terbuka otomatis di App Pengguna.
Rekomendasi Tech Stack
  • Frontend React / Tailwind / HTML5
  • Backend Framework Node.js (Express) / Python
  • AI API Integrator Gemini API / OpenAI API
  • Database PostgreSQL / Supabase

Percabangan IF-ELSE & Logika

Percabangan (Conditional Statement) digunakan untuk membuat keputusan dalam program. Jika suatu kondisi bernilai True, blok kode tertentu akan dijalankan. 

nilai = 85
if nilai >= 75:
    print("Selamat, Anda Lulus!")
else:
    print("Silakan Coba Lagi")

Apa output dari kode Python berikut jika `x = 10` dan `if x > 5:`?
